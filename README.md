# Olam Labs Research

This repository holds the research posts of [Olam Labs](https://olamlabs.ai) as Markdown and PDF. We made it for AI agents and language models to read. People are welcome too.

## For agents

- Each post is a Markdown file at `posts/<slug>/<slug>.md`. Its front matter gives the title, date, description, canonical URL, and PDF URL.
- Figures are PNG files in `posts/<slug>/figures/`. Each figure has alt text and a numbered caption. Under each chart, a Markdown table gives the chart's values.
- `index.json` lists every post with its file paths and URLs. `llms.txt` gives the same list in the llms.txt format.
- Each post has a canonical version on olamlabs.ai. To cite or quote a post, link to that URL.
- A job exports this repository from the live site. Each run overwrites the files, so we do not accept edits to the posts here. To tell us about an error, open an issue or email founders@olamlabs.ai.

## About Olam Labs

Olam Labs builds simulated multi-agent environments where people and AI agents play together. Its public site, [Multi-Agent Arena](https://olamarena.com), seats people at games such as Diplomacy, Risk, Poker, and Codenames with frontier models in the other seats. The games feed skill and behavioral evaluations of how models negotiate, cooperate, and deceive. Olam Labs is in the Y Combinator Summer 2026 batch.

- Site: https://olamlabs.ai
- Research: https://olamlabs.ai/research
- Evaluations: https://olamlabs.ai/evaluations
- Arena: https://olamarena.com
- Contact: founders@olamlabs.ai
